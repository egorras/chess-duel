# chess-duel

A repository containing chess-related tools and dashboards.

## Projects

### 📊 [Chess Duel Dashboard](docs/)
A GitHub Pages website displaying chess game statistics from Lichess for two players.

### 🤖 [Lichellange Bot](lichellange-bot/)
A Telegram bot for creating Lichess chess challenges directly from Telegram chat.

### ♞ [Plasma Widget](plasma-widget/)
A Plasma 6 widget showing the current month's duel score with Lichess sign-in,
and an on-demand action that accepts an existing or creates a new casual challenge.
